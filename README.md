# Rack & Recall

A word-study app for Scrabble players: spaced-repetition cardboxes (FSRS), anagram, hook, build, blank and definition quizzes, word search and lists, games, and stats.

## Get it

- **Any device:** download [`rack-and-recall.html`](https://github.com/jawnhealy/Rack-Recall-app/raw/main/rack-and-recall.html) and open it in a browser (Chrome, Edge, Safari or Firefox). It runs offline once loaded.
- **Android app:** installed apps check this repository for updates (Settings → App updates → Check for updates).

## Sync

Create a free account under Settings → Sync between devices, then sign in with it on each device. Each device keeps a full copy and works offline.
